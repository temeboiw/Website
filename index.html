SentinelOS V10. The release that never lies about itself.

The first official stable public release of SentinelOS: a Windows-compatible desktop OS built on the existing SentinelOS kernel. No placeholder APIs, no invented benchmarks, no false claims. It ships when it is verified, not before.

Rules that can’t bend

Fifteen non-negotiables guide V10. These six define the character of the release.

One kernel

The existing SentinelOS kernel stays. No second kernel, no renaming files to fake a new one.

No fake exports

Every API returns correct values, structures and errors. An export that only says “success” is a bug.

Tested or not claimed

Compatibility is listed only after a real test. No universal Windows claims.

Honest graphics

If the CPU is drawing the screen, the OS says so. No false GPU acceleration.

Your data first

Installs and updates never touch user data. Destructive disk work needs explicit confirmation of the exact target disk.

Verified push only

Develop in place on main, with no dev commits. One verified release commit goes to origin/main.

Everything, one architecture

Ten steps to official

V10 moves through controlled stages. Pick a stage to see what it must prove.

Bugs, ranked

P0 and P1 issues block release. No known data-corruption or critical security issues are allowed through.

P0

Critical security, data loss or unbootable system.

P1

Major functionality failure or severe instability.

P2

Significant feature defect.

P3

Minor defect or cosmetic issue.

The release gate

V10 cannot be called released until all 18 criteria pass. Each one is marked only after independent verification, and the ISO stays locked until every box is checked. Come back to see progress.
